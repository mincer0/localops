## 本轮修复

### 在线发现项“忘记记录”无效

在线监听项即使从目录删除，也会在紧接着的扫描中重新出现。现在待登记服务只提供“登记为服务”；服务停止并进入“最近掉线”后，才允许忘记历史记录。Core 同时增加防御性校验，避免未来其他调用方绕过 UI。

### 筛选后详情仍显示旧服务

服务来源或搜索条件变化后，右侧详情曾可能继续显示已经不在列表中的旧选中项。现在详情只从筛选结果取值，并在来源、搜索或 snapshot 变化时自动校正选择。

对应 Swift 自动化由 8 项增加至 10 项，新增登记流程与在线/离线忘记流程回归。

## 原生 UI 自动控制边界

菜单栏弹窗的读取和刷新可以真实执行。点击进入 SwiftUI 管理窗口后，本轮环境的 macOS UI 控制服务会断开，但 LocalOps 进程没有崩溃，Web/API 和 8042 监听保持正常；重新打开 App 也始终只有一个进程。因此没有把管理窗口内部的逐控件点击计入上述 30 个通过项，仍建议发布前人工确认服务页、事件页和设置页。
